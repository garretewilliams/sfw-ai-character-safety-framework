# Contributing

Useful contributions:

- **Challenge a rule** in POLICY.md. Explain the case it handles badly.
- **Propose a borderline case** with your suggested treatment.
- **Add a test case** to EVALUATION.md with clear pass criteria, especially false-positive checks.
- **Report results** from running the evaluation on any platform, including your own. Report failures as well as passes, and state your affiliation.

Please do **not** post:

- real conversations containing personal information;
- anyone's crisis disclosures;
- sexual content of any kind;
- working methods of self-harm, even as test inputs. Describe a test case instead of reproducing harmful text.

Changes to the minors and self-harm areas need a public issue first, and ideally review by someone with trust-and-safety or clinical experience.

To report a safety problem in the ChatBrat product, email safety@chatbrat.ai rather than opening an issue here.
